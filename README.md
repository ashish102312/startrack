# Startrack - Modern Real-Time Incident Tracker 🚀

Startrack is a high-performance, real-time incident management platform engineered for modern DevOps and site reliability engineering teams.

![Startrack Banner](client/public/vite.svg)

## Features
- **Real-Time Sync**: Instant incident updates powered by WebSockets.
- **Observability Dashboard**: Live metric counters for open, active, and resolved incidents.
- **Resolution History**: Track solved incidents and post-mortems.
- **Interactive Feedback**: Share feedback with rating and community reviews.
- **Enterprise Grade Security**: Rate limiting, Helmet HTTP protections, and JWT authentication.

## Quick Start
```bash
./start.sh
```
